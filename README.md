# 🧬 AI Drug Repurposing Platform

## 📌 Overview

This project uses Machine Learning to identify potential new therapeutic uses for existing drugs. The goal is to help researchers prioritize promising drug–disease pairs for further laboratory investigation.

> **Note:** This project generates research hypotheses. It does **not** recommend treatments or replace laboratory or clinical validation.

---

## 🎯 Objectives

- Learn bioinformatics concepts
- Build a complete Data Science pipeline
- Perform data preprocessing
- Train machine learning models
- Explain predictions using Explainable AI (SHAP)
- Build an interactive Streamlit application
